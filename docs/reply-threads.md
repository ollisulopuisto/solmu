# Reply chains and thread controls

The chain button opens the loaded thread containing the exact message. For a
reply, Cmd-click on macOS or Ctrl-click on other platforms jumps to the original
quoted message. Modified Enter on the focused button does the same. On macOS
Ctrl-click remains a secondary click, not the source-jump gesture. The accessible
button name includes the quoted sender.

Timeline replies reserve48points above their bubble: room for the chain and a
short fading continuation at rest. Inside a thread the repeated chain buttons
are absent; exact visible parent-child routes remain drawn. Missing/offscreen
endpoints do not invent a route.

The synthetic refined-thread demo page intentionally opens the modal for CI
evidence, as does reply-thread. chain-above-outgoing retains timeline evidence.
Only explicit --demo-page values enable this fixture, never a substring in an
unrelated argument. No real conversations are used.
