# First-message tail

The first message of each sender, source-chat and calendar-day run owns the
existing top-corner speech tail. Middle and last messages have no ordinary tail.
The tail outline, avatar placement and six-point bubble overlap are unchanged.
Linked timelines and the separate thread pane use the same boundary rule;
thread spacing stays separate. Bubbleless messages stay bubbleless and do not
transfer tail ownership to a later message. Existing reply-chain controls are
unchanged and remain distinct from the ordinary speech tail.

This supersedes the earlier last-message proposal. No show/hide, chronology or
interleaving design is included.
